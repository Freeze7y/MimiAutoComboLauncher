# 米米自动连招启动器

轻量 Android 工具，为小米 / 黑鲨原生宏提供便捷入口。

**选择应用 → 启动游戏 → 使用系统原生宏。**

Java + Android 原生界面，无第三方运行时框架。不会修改游戏 APK，也不实现触摸注入或新的连招引擎。

## 下载

从 [GitHub Releases](https://github.com/Freeze7y/MimiAutoComboLauncher/releases/latest) 下载 APK。

当前版本 **1.1.0**，原名「原生宏助手」。沿用原包名和签名，可以覆盖旧版本安装。

## 功能

- 已安装应用列表、名称/包名搜索、收藏和最近使用。
- 一键启动游戏并调用原生宏、打开宏面板、手动停止。
- 通知直接通过广播控制宏，不把助手界面带到游戏前台。
- 游戏快捷方式使用游戏自己的图标。
- 前台会话通知；不因返回桌面自动停止宏。
- 简约卡片界面、深色模式、随列表滚动收起的顶部区域。
- 本地 GIF 展示，隐藏时停止播放；本地诊断日志和权限引导。

## 支持范围

- 最低 Android 10（API 29）；当前 compileSdk / targetSdk 为 36。
- 手机必须具有 `com.xiaomi.macro` 或 `com.blackshark.macro` 及可调用的 `MainService`。
- 用户已在其 Android 17 / HyperOS 4 环境反馈既有版本的核心功能可用；没有完成所有机型、MIUI 或 HyperOS 版本的兼容测试。
- 原生服务是否接受请求、游戏是否支持，取决于系统组件。应用显示“请求已发送”不等于已解锁游戏工具箱入口。

## 使用

1. 安装后打开助手，按提示处理所需权限。
2. 搜索游戏并点击，选择“启动游戏并开启原生宏”。
3. 游戏中点击助手通知打开原生面板；停止按钮位于通知操作区。不同系统的通知展开方式可能不同。
4. 可收藏游戏或创建桌面快捷方式。
5. 遇到问题，在“设置与诊断”复制诊断信息，提交 [Issue](https://github.com/Freeze7y/MimiAutoComboLauncher/issues)。

助手不申请无障碍、使用情况访问或自身悬浮窗权限。通知权限由应用请求；系统要求用户确认的授权不能自动代为同意。前台服务也不能保证永不被系统回收。

覆盖升级后若桌面仍保留旧名称或图标，可先重启手机刷新；已有用户通过重启解决了桌面旧图标缓存问题。

## 实现概要

通过显式 Intent 调用厂商的 `<package>.MainService`：

- `gamePackage`：目标应用包名。
- `clickIcon=false`：启动游戏后的宏服务请求。
- `clickIcon=true`：打开原生宏面板。

通知使用非导出的 BroadcastReceiver，助手使用用户主动启动的前台会话。停止宏只能由用户明确操作触发，助手服务销毁不会主动关闭厂商宏服务。

本项目参考了对第三方宏助手 APK 的静态研究，应用代码独立实现；原 APK 和反编译结果不在本仓库中。

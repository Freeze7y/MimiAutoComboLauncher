# 更新记录

## 1.2.1 — 通知点击与停止处理

- 取消打开面板的 1.5 秒去重，每次通知点击均尝试调用原生组件；保留启动游戏的重复点击保护。
- 停止接口返回 false 不再误报失败，重复停止可以正常结束助手会话；真正的权限异常仍明确提示。
- 即使原生停止请求异常，也独立清理助手服务和通知。
- 已有游戏会话的面板沿用会话组件，避免修改组件设置后调用错目标。
- 日志增加通知操作接收记录和原始停止返回值，方便区分通知未送达与原生组件未显示面板。
- 54 项主机回归断言通过；未连接手机，不保证所有系统端首次点击问题均已解决。

停止返回值依据：[Android Context.stopService](https://developer.android.com/reference/android/content/Context#stopService(android.content.Intent))。返回 false 表示没有匹配的运行服务，不是停止失败回执。

## 1.2.0 — 关于与 GitHub 更新检查

- 右上角增加固定“关于”入口，显示已安装版本、检查更新和项目链接。
- 增加默认关闭的自动更新检查开关，仅在打开应用时请求 GitHub 最新正式 Release，每 6 小时最多一次。
- 按数字比较版本；支持超时、网络失败和 API 限流提示，不自动下载安装。
- 新增 INTERNET 声明权限，无需系统运行时授权。无 GitHub 登录和个人数据上传。
- 45 项主机回归断言、编译和签名检查；尚未真机验证本次界面与网络流程。

## 1.1.0 — 米米自动连招启动器

- 项目正式命名为「米米自动连招启动器」，原名「原生宏助手」。
- 更新应用名称、界面标题、诊断名称和发布文件名。
- 保留包名、签名、原生宏调用路径与已有功能，可覆盖升级。
- 首次发布公开 GitHub 源码和 APK。

## 已有功能与修复

- 通知广播直接打开原生宏，避免通知点击切回助手。
- 前台会话、手动停止、无自动关闭宏。
- 搜索、收藏、游戏快捷方式、应用原图标。
- 失败请求可立即重试，通知权限与频道状态分别检查。
- 简约深浅色界面、GIF、随列表滚动的顶部区域。
- 标准自适应应用图标；部分桌面的旧图标缓存需重启后刷新。

发布验证：39 项主机回归断言、Java/R8 构建、APK 签名与对齐检查。1.1.0 改名版未单独进行真机回归。
